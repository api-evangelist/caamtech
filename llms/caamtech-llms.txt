# CaaMTech

> CaaMTech is a pharmaceutical drug discovery company in Issaquah, Washington, founded by
> Dr. Andrew Chadeayne, engineering next-generation psychedelic-inspired small-molecule
> therapeutics for mental health conditions. It synthesizes and characterizes novel
> tryptamines, screens natural and synthetic compounds for safety and efficacy, publishes
> fundamental chemical and pharmacological research, and builds a patent portfolio around
> the results.

CaaMTech operates **no developer programme** and publishes no product API, SDK, webhook
surface or developer documentation. The only machine-readable surface on caam.tech is the
standard WordPress REST API that serves the company web site — its published research
updates, pages, media and taxonomy are readable as JSON without credentials — plus an
authenticated WordPress MCP adapter endpoint whose tool list is not publicly introspectable.

This file was **generated by API Evangelist**, not published by CaaMTech. `caam.tech/llms.txt`
returned HTTP 404 when probed on 2026-08-08.

## APIs

- [CaaMTech WordPress REST API](https://caam.tech/wp-json/): the site's WordPress REST discovery document — 155 routes across 10 namespaces. Base URL `https://caam.tech/wp-json`. Anonymous reads; WordPress Application Password required for writes.
- [WordPress MCP adapter](https://caam.tech/wp-json/mcp): deployed MCP server at `/wp-json/mcp/mcp-adapter-default-server`. Anonymous `tools/list` returns HTTP 401; the tool set is not public.
- [WordPress Abilities registry](https://caam.tech/wp-json/wp-abilities/v1): the capability registry backing the MCP adapter. Index readable anonymously.

## Most useful endpoints

- `GET https://caam.tech/wp-json/wp/v2/posts` — published research updates and announcements as JSON.
- `GET https://caam.tech/wp-json/wp/v2/posts/{id}` — one update in full.
- `GET https://caam.tech/wp-json/wp/v2/pages` — static site pages.
- `GET https://caam.tech/wp-json/wp/v2/media` — images and PDFs.
- `GET https://caam.tech/wp-json/wp/v2/search` — search across posts and pages.
- `GET https://caam.tech/wp-json/wp/v2/categories` and `/tags` — taxonomy for resolving post `categories[]` / `tags[]` ids.

Pagination is `page` + `per_page` (max 100), with `X-WP-Total`, `X-WP-TotalPages` and an
RFC 8288 `Link` header. Use `_fields` for sparse responses and `_embed` to inline author,
media and terms. There is no idempotency contract and no rate-limit headers; the host is
behind Cloudflare, which may answer a non-2xx with HTML rather than the JSON error envelope.
